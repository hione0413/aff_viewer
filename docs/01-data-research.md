# 대한민국 기업 계열사 데이터 조사

## 개요

대한민국 기업의 계열사 정보를 시각적으로 보여주는 서비스 개발을 위한 데이터 소스 조사 결과입니다.

---

## 데이터 소스 현황

### 1. 기업집단포털 (공정거래위원회) - 주요 데이터 소스

| 항목 | 내용 |
|------|------|
| URL | https://www.egroup.go.kr |
| 제공 기관 | 공정거래위원회 |
| 대상 | 대규모기업집단 (자산 5조원 이상) |
| 기업집단 수 | 약 80개 그룹 |
| 계열사 수 | 약 2,000+ 개사 |
| API 제공 | REST API (공공데이터포털 연계) |
| 비용 | 무료 |

### 2. 금융위원회 기업기본정보 API

| 항목 | 내용 |
|------|------|
| URL | https://www.data.go.kr/data/15043184/openapi.do |
| 제공 정보 | 개별 기업의 계열회사 현황, 연결대상 종속기업 |
| 특징 | 법인등록번호/기업명으로 조회, 지배구조 분석 가능 |

### 3. OPENDART (금융감독원)

| 항목 | 내용 |
|------|------|
| URL | https://opendart.fss.or.kr |
| 제공 정보 | 상장사 사업보고서, 지분보고서, 재무정보 |
| 특징 | 상장사 중심, 계열사 지분율 등 상세 정보 |

1. 지정된 대규모기업집단 조회

6. 소속회사 주주현황
7. 소속회사 임원현황
8. 특수관계인 내부지분 현황
9. 기업집단별 순환출자 현황
10. 내부지분(대동비교) 현황
11. 지주회사 자회사 및 손자회사 현황
12. 지주회사 설립·전환 신고현황
13. 계열 편입/제외/유예 변경내역

15. 사용 가능 공개년월 조회

### 핵심 API #1: 지정된 대규모기업집단 조회

> 모든 대규모기업집단 목록을 조회합니다.

**엔드포인트**
```
GET https://apis.data.go.kr/1130000/appnGroupSttusList/appnGroupSttusListApi
```

**요청 파라미터**

| 파라미터 | 타입 | 필수 | 설명 | 예시 |
|---------|------|:----:|------|------|
| ServiceKey | string | O | 공공데이터포털 인증키 | - |
| pageNo | string | O | 페이지 번호 | 1 |
| numOfRows | string | O | 페이지당 결과 수 | 100 |
| presentnYear | string | O | 기업집단 지정년월 (YYYYMM) | 202405 |

**응답 필드**

| 필드 | 타입 | 설명 | 예시 |
|------|------|------|------|
| resultCode | string | 결과코드 | 00 |
| resultMsg | string | 결과메시지 | OK |
| totalCount | string | 전체 결과 수 | 80 |
| unityGrupNm | string | 기업집단명 | 삼성 |
| unityGrupCode | string | 기업집단코드 | K1000032 |
| smerNm | string | 동일인(총수) | 이재용 |
| repreCmpny | string | 대표회사 | 삼성전자(주) |
| sumCmpnyCo | string | 계열회사 수 | 59 |
| invstmntLmtt | string | 집단 구분 | 상호출자제한집단 |
| entrprsCl | string | 공기업 구분 | 일반 |

**호출 예제**
```
GET https://apis.data.go.kr/1130000/appnGroupSttusList/appnGroupSttusListApi
    ?ServiceKey={인증키}
    &pageNo=1
    &numOfRows=100
    &presentnYear=202405
```

### 추가 활용 API

| API | 용도 | 시각화 활용 |
|-----|------|------------|
| 소속회사 참여업종 정보 | 각 계열사의 업종, 대표상품 | 업종별 그룹핑, 필터링 |
| 소속회사 재무현황 | 자산, 매출, 당기순이익 | 노드 크기 표현 |
| 소속회사 주주현황 | 지분율 정보 | 출자 관계 엣지 표현 |
| 특수관계인 내부지분 현황 | 총수 일가 지분 | 지배구조 시각화 |
| 순환출자 현황 | 출자 구조 | 순환 출자 하이라이트 |
| 지주회사 자회사/손자회사 현황 | 지주회사 구조 | 계층 트리 구조 |

## API 사용 조건

| 항목 | 내용 |
|------|------|
| 비용 | 무료 |
| 일일 호출 제한 | 10,000회 (개발 계정) |
| 호출 제한 증량 | 활용사례 등록 시 가능 |
| 승인 방식 | 자동승인 |
| 응답 형식 | XML |
| 인증키 발급 | 공공데이터포털 가입 후 이용신청 |

**인증키 발급 절차**
1. [공공데이터포털](https://www.data.go.kr) 회원가입
2. 해당 API 검색 후 "활용신청" 클릭
3. 활용 목적 작성 후 신청
4. 자동승인 후 인증키 발급 (즉시)
