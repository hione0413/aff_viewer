## 1. AdMob 계정 생성

### 1.1 AdMob 사이트 접속

1. 브라우저에서 **https://admob.google.com** 접속
2. **시작하기** 버튼 클릭

### 1.2 Google 계정 로그인

- 기존 Google 계정으로 로그인
- 계정이 없다면 새로 생성

### 1.3 AdMob 가입 정보 입력

1. **국가**: 대한민국 선택
2. **시간대**: (GMT+09:00) 서울 선택
3. **결제 통화**: KRW (대한민국 원) 선택
4. 이용약관 동의 체크
5. **AdMob 계정 만들기** 클릭

### 1.4 결제 정보 설정 (수익 지급용)

> 나중에 설정해도 됩니다. 수익이 발생하면 지급받기 위해 필요합니다.

1. AdMob 콘솔 → 좌측 메뉴 → **결제**
2. 결제 프로필 생성
3. 은행 계좌 정보 입력

## 2. 앱 등록

### 2.1 앱 추가 시작

1. AdMob 콘솔 접속
2. 좌측 메뉴에서 **앱** 클릭
3. **앱 추가** 버튼 클릭

### 2.2 플랫폼 선택

```
┌─────────────────────────────────────┐
│  앱 추가                             │
├─────────────────────────────────────┤
│                                     │
│  플랫폼을 선택하세요                  │
│                                     │
│  [Android]  ← 이것 선택              │
│  [iOS]                              │
│                                     │
└─────────────────────────────────────┘
```

**Android** 선택 후 **계속** 클릭

### 2.3 앱 스토어 등록 여부

```
┌─────────────────────────────────────┐
│  이 앱이 지원되는 앱 스토어에          │
│  등록되어 있나요?                     │
│                                     │
│  ○ 예                               │
│  ● 아니요  ← 아직 출시 전이면 선택     │
│                                     │
└─────────────────────────────────────┘
```

- **아니요** 선택 (아직 Play 스토어에 출시하지 않은 경우)
- **계속** 클릭

### 2.4 앱 이름 입력

```
┌─────────────────────────────────────┐
│  앱 이름                             │
│  ┌─────────────────────────────────┐│
│  │ 기업족보                         ││
│  └─────────────────────────────────┘│
│                                     │
│  [앱 추가]                           │
└─────────────────────────────────────┘
```

1. 앱 이름: `기업족보` 입력
2. **앱 추가** 클릭

### 2.5 앱 ID 확인 (중요!)

앱 추가 완료 후 **앱 ID**가 표시됩니다:

```
┌─────────────────────────────────────┐
│  앱이 추가되었습니다!                 │
│                                     │
│  앱 ID:                             │
│  ca-app-pub-1234567890123456~9876543210  │
│           ↑                         │
│       이 ID를 메모하세요!             │
│                                     │
│  [광고 단위 만들기]                   │
└─────────────────────────────────────┘
```

**앱 ID 형식**: `ca-app-pub-XXXXXXXXXXXXXXXX~XXXXXXXXXX`
- `~` (물결표) 포함
- 이 ID를 복사해서 메모장에 저장하세요

## 3. 광고 단위 생성

### 3.1 광고 단위 추가

1. 앱 추가 완료 화면에서 **광고 단위 만들기** 클릭
   - 또는: 좌측 메뉴 → 앱 → 기업족보 → 광고 단위 → 광고 단위 추가

### 3.2 광고 형식 선택

```
┌─────────────────────────────────────┐
│  광고 형식 선택                       │
├─────────────────────────────────────┤
│                                     │
│  [배너]  ← 이것 선택                  │
│  화면 상단 또는 하단에 표시되는        │
│  직사각형 광고                        │
│                                     │
│  [전면]                              │
│  전체 화면을 덮는 광고                │
│                                     │
│  [리워드]                            │
│  보상을 제공하는 광고                 │
│                                     │
│  [네이티브]                          │
│  앱 디자인에 맞춤형으로 표시          │
│                                     │
└─────────────────────────────────────┘
```

**배너** 선택

### 3.3 광고 단위 이름 입력

```
┌─────────────────────────────────────┐
│  광고 단위 이름                       │
│  ┌─────────────────────────────────┐│
│  │ banner_bottom                   ││
│  └─────────────────────────────────┘│
│                                     │
│  [광고 단위 만들기]                   │
└─────────────────────────────────────┘
```

1. 광고 단위 이름: `banner_bottom` 입력
2. **광고 단위 만들기** 클릭

### 3.4 광고 단위 ID 확인 (중요!)

```
┌─────────────────────────────────────┐
│  광고 단위가 생성되었습니다!          │
│                                     │
│  광고 단위 ID:                       │
│  ca-app-pub-1234567890123456/1111111111  │
│           ↑                         │
│       이 ID도 메모하세요!             │
│                                     │
│  [완료]                              │
└─────────────────────────────────────┘
```

**광고 단위 ID 형식**: `ca-app-pub-XXXXXXXXXXXXXXXX/XXXXXXXXXX`
- `/` (슬래시) 포함 (앱 ID의 `~`와 다름!)
- 이 ID도 복사해서 메모장에 저장하세요

### 3.5 ID 정리

메모장에 다음과 같이 정리하세요:

```
=== 기업족보 AdMob ID ===

앱 ID (AndroidManifest.xml용):
ca-app-pub-1234567890123456~9876543210

배너 광고 단위 ID (ad-service.ts용):
ca-app-pub-1234567890123456/1111111111
```

## 4. 앱에 실제 ID 적용

### 4.1 앱 ID 적용 (AndroidManifest.xml)

파일 위치: `packages/web/android/app/src/main/AndroidManifest.xml`

**수정 전** (테스트용 ID):
```xml
<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="ca-app-pub-3940256099942544~3347511713"/>
```

**수정 후** (실제 ID):
```xml
<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="ca-app-pub-1234567890123456~9876543210"/>
                   ↑ 여기에 본인의 앱 ID 입력
```

### 4.2 광고 단위 ID 적용 (ad-service.ts)

파일 위치: `packages/web/src/services/ad-service.ts`

**수정 전**:
```typescript
// 테스트용 광고 단위 ID (배포 전 실제 ID로 교체 필요)
const TEST_BANNER_ID = 'ca-app-pub-3940256099942544/6300978111'

// 실제 광고 단위 ID (AdMob 콘솔에서 발급받은 ID로 교체)
// const PROD_BANNER_ID = 'ca-app-pub-XXXXXXXXXXXXXXXX/XXXXXXXXXX'

// ...

const BANNER_AD_ID = TEST_BANNER_ID // 배포 시 PROD_BANNER_ID로 변경
```

**수정 후**:
```typescript
// 테스트용 광고 단위 ID
const TEST_BANNER_ID = 'ca-app-pub-3940256099942544/6300978111'

// 실제 광고 단위 ID
const PROD_BANNER_ID = 'ca-app-pub-1234567890123456/1111111111'
                        ↑ 여기에 본인의 광고 단위 ID 입력

// ...

const BANNER_AD_ID = PROD_BANNER_ID  // 이렇게 변경
```

## 5. 테스트

### 5.1 빌드 및 실행

```bash
cd packages/web

# 1. 웹 빌드
npm run build

# 2. Android 동기화
npx cap sync android

# 3. Android Studio 열기
npx cap open android
```

### 5.2 Android Studio에서 실행

1. Android Studio가 열리면 프로젝트 동기화 대기
2. 상단의 기기 선택 (에뮬레이터 또는 실제 기기)
3. ▶️ Run 버튼 클릭

### 5.3 테스트 광고 확인

- 개발 모드에서는 **테스트 광고**가 표시됩니다
- "Test Ad" 또는 "테스트 광고" 라벨이 붙어있음
- 이것이 정상입니다!

```
┌─────────────────────────────────┐
│                                 │
│        앱 콘텐츠 영역            │
│                                 │
├─────────────────────────────────┤
│  [Test Ad] Google 테스트 광고    │  ← 하단에 표시
└─────────────────────────────────┘
```

### 5.4 웹 브라우저에서는?

- **웹 브라우저에서는 광고가 표시되지 않습니다**
- AdMob은 네이티브 앱 전용입니다
- `pnpm dev`로 실행하면 콘솔에 다음 메시지가 표시됩니다:
  ```
  [AdMob] 웹 환경에서는 광고가 표시되지 않습니다.
  ```

## 자주 묻는 질문 (FAQ)

### Q: 광고가 안 나와요

**A:** 다음을 확인하세요:
1. 실제 Android 기기/에뮬레이터에서 실행 중인가요? (웹 브라우저 X)
2. 앱 ID가 `AndroidManifest.xml`에 올바르게 입력되었나요?
3. 인터넷이 연결되어 있나요?

### Q: 테스트 광고만 나와요

**A:** 정상입니다! 개발 모드에서는 테스트 광고만 표시됩니다.
프로덕션 빌드 후 실제 광고가 표시됩니다.

### Q: 수익은 언제 발생하나요?

**A:**
1. 실제 ID를 적용하고
2. Play 스토어에 앱을 출시한 후
3. 사용자가 광고를 보거나 클릭하면 수익이 발생합니다

### Q: 수익은 어떻게 받나요?

**A:**
1. AdMob 콘솔 → 결제 → 결제 프로필 설정
2. 은행 계좌 등록
3. 최소 지급 기준 ($100) 달성 시 매월 지급

### Q: 앱 ID와 광고 단위 ID가 뭐가 다른가요?

**A:**
- **앱 ID** (`~` 포함): 앱 전체를 식별, `AndroidManifest.xml`에 사용
- **광고 단위 ID** (`/` 포함): 개별 광고 위치 식별, 코드에서 사용
